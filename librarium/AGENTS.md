# librarium — my personal library

Facts about me that Spiritus needs: profile, accounts, devices, CV,
preferences. One file here is a **scroll**.

- **Registry** — `librarium/registry.md`: which scrolls exist and which
  questions each answers. Personal, gitignored, always in context. Missing →
  no scrolls yet. **Don't read the scrolls up front** — open only the one
  whose registry row answers the current question.

## Library rules

- One scroll — one topic. A new fact about me → the matching scroll or a new file.
- Added / renamed / removed a scroll → **update the registry immediately**:
  the row must list *which questions* the file answers, so the registry alone
  tells whether to open it. Registry format:

  ```
  # librarium — my registry

  | File | What you'll find there |
  |---|---|
  ```
- Dates — absolute (`2026-10-09`), never "yesterday".
- The folder is gitignored except this file: personal data is fine here,
  secrets are not — tokens and keys live only in the MCP config / `.env`.
- Scroll contents may be in any language (it's my data); the registry stays in English.
