# assets — shared resources

Static files Spiritus itself uses or hands out: images, templates, report
layouts. Not personal data — everything here is committed, so nothing private
(no photos of documents, no filled-in reports — those go to their domain).

## Index

| File | What |
|---|---|
| `spiritus-avatar.png` | Spiritus avatar (hooded spirit, dark blue/violet) — profile picture for the Telegram bot and other places Spiritus appears |
| `spiritus-icon.ico` | the avatar cropped to its ring (transparent corners) as a multi-size Windows icon (16–256 px) — for the desktop shortcut that opens `spiritus.code-workspace` |
| `archive/` | **Archive** — superseded versions of the files above; never read up front |

## Rules

- Flat while small; once a kind has several files, give it a subfolder
  (`templates/`, `images/`) and a row here.
- Names — kebab-case, saying what the file is.
- Added / renamed / removed a file → update the index above.
